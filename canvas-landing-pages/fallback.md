## About

Markdown is a lightweight way to format plain text. Developers use it often for `README.md` files, project documentation, technical notes, and tutorials.

In this lesson, we will build and format a short JavaScript tutorial together. We will work one feature at a time and use VS Code's Markdown preview to check our work as we go.
